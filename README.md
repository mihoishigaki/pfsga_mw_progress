# pfsga_mw_progress

A viewer for tracking the observation progress of the PFS-SSP Galactic Archaeology (GA) outer Milky Way survey.

The Prime Focus Spectrograph (PFS) Subaru Strategic Program (SSP) includes a Galactic Archaeology survey targeting the outer Milky Way. This repository maintains a web-based viewer that shows which fields have been observed, how far the survey has progressed, and what remains to be observed.
